# Full Datetime Year

Odoo 19 shortens readable date and datetime values for the current year, for
example `Jun 4, 10:30 AM` instead of `Jun 4, 2026, 10:30 AM`.

Install this module to keep the year visible for date and datetime fields in the
backend web client. No configuration is required.

## Installation

1. Copy `full_datetime_year` into an Odoo 19 addons path.
2. Update the Apps list.
3. Install **Full Datetime Year**.
4. Refresh the browser so Odoo rebuilds/loads the backend asset bundle.
